# Java Learning

A structured journey through Java programming, following the Bro Code Java course while organizing concepts according to their actual place in the Java language.

## Learning Source

- Bro Code — Java Full Course
- JDK: Java 25 LTS
- IDE: Visual Studio Code

## Topics Covered

| # | Topic | Description |
|---|---|---|
| 01 | Basics | Java fundamentals, variables, input/output, type conversion, arithmetic, Math, random numbers, etc. |
| 02 | Control Flow | Conditional statements, logical operators, loops, break and continue |
| 03 | Methods | Methods, method overloading, scope, and varargs |
| 04 | Arrays | Arrays, user input, searching, and multidimensional arrays |
| 05 | Strings | String methods and substring operations |
| 06 | Object-Oriented Programming | Classes, objects, constructors, inheritance, polymorphism, abstraction, interfaces, composition, and more |
| 07 | Collections | ArrayList, HashMap, and enums |
| 08 | Generics | Generic classes, methods, and types |
| 09 | Exception Handling | Exception handling and error management |
| 10 | File Handling | Reading and writing files |
| 11 | Date & Time | Java date and time APIs |
| 12 | Concurrency | Threads, multithreading, and TimerTasks |
| 13 | Projects | Practical Java programs and projects |
| 99 | Notes | Java vs C++, syntax references, important concepts, and revision material |
